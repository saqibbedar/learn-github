# About Gitcraft

Gitcraft began as a personal reference for Git commands that are easy to forget and difficult to reconstruct under pressure. It grew into a small documentation project for learning how a practical documentation site is designed, organized, written, and maintained.

The goal is simple: explain Git clearly enough that a reader can understand the command, recognize the situation, and use the workflow with confidence.

## About the creator

Gitcraft is created and maintained by [Saqib Bedar](https://saqibbedar.github.io), a developer interested in Python, AI/ML, developer tooling, and clear technical writing.

## Support the project

If Gitcraft helps you, you can support its continued development through [Buy Me a Coffee](https://www.buymeacoffee.com/saqibbedar).

## Future contributors

The project is intentionally small while its foundations are being refined. Future contributors can help improve command accuracy, clarify examples, add missing Git workflows, and make the reference easier to search.

See the [contribution guide](https://github.com/saqibbedar/gitcraft/blob/main/CONTRIBUTING.md) for the GitHub workflow.
