# Changelog

All notable changes to Gitcraft are documented here. Releases follow semantic versioning: `MAJOR.MINOR.PATCH`.

<a id="release-v0.1.0"></a>

## [0.1.0] - 2026-09-03

### Added

- Initial Gitcraft documentation site powered by Zensical.
- Getting Started guide for Git and GitHub, installation, configuration, core commands, and remotes.
- Reference sections for Core Git, Branches, Stash, Remotes, Undo and Recovery, Repository Practices, Collaboration, and Open Source workflows.
- Practical coverage for `.gitignore`, Git tags, Git LFS, Conventional Commits, reflog recovery, and pull requests.
- Light and dark color palettes, search tags, Mermaid workflows, and GitHub Pages deployment.

### Changed

- Established the Gitcraft visual identity, repository homepage, contribution workflow, and semantic documentation navigation.
