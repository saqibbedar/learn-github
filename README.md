# Gitcraft

A practical, readable Git reference for everyday workflows and long-term mastery.

Gitcraft explains the mental model behind Git, then turns it into commands and workflows you can use at the terminal. It is designed for quick lookup without losing the reasoning that makes Git easier to remember.

## Explore Gitcraft

| Need                       | Start here                                             |
| -------------------------- | ------------------------------------------------------ |
| Learn the foundations      | [Getting Started](docs/get-started/git-vs-github.md)   |
| Create or manage branches  | [Branches](docs/branches/index.md)                     |
| Temporarily set work aside | [Git stash](docs/stash/index.md)                       |
| Synchronize with GitHub    | [Remote workflows](docs/remotes/index.md)              |
| Undo or recover changes    | [Undo and Recovery](docs/undo-recovery/index.md)       |
| Contribute to a project    | [Open Source workflow](docs/opensrc-workflow/index.md) |

## Reference areas

- Core Git concepts and the working-tree-to-commit model.
- Branch, merge, rebase, stash, and remote workflows.
- Undo and recovery with `restore`, `reset`, `revert`, and `reflog`.
- Repository practices including `.gitignore`, tags, and Git LFS.
- Collaboration practices such as pull requests and Conventional Commits.
